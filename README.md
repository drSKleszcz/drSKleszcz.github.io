# Sławosz Kleszcz

Personal portfolio covering engineering research, numerical modeling, data analysis and software.

[English](https://www.drskleszcz.pl/) | [Polski](https://www.drskleszcz.pl/pl/)

Built with Jekyll and hosted on GitHub Pages.

## Local development

Requires Ruby 3.3 and Bundler.

```sh
bundle install
bundle exec jekyll serve
```

Open http://localhost:4000.
